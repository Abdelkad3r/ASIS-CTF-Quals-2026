TL;DRAttention in a lab coat

Unwinding the einsum turns the "Hamiltonian" into a plain softmax-attention PRF. The secret is 60 numbers per round (all ~U(0.5,2)), regenerated each of 7 rounds; we get ≤1200 exact eval queries, then must predict 6 random sequences to 1e-6.

Because the oracle is noise-free, any parameters reproducing ~150 tags reproduce T everywhere — a functional twin, not the true secret. We fit all 60 by Levenberg–Marquardt with an exact analytic Jacobian, restarting from the U(0.5,2) prior until the residual hits ~1e-15, then forge. Pipelining the queries and running restarts in parallel keeps it inside the per-connection time budget.

01Protocol

After a 20-bit SHA-256 proof of work, each of 7 rounds accepts:

  • eval <json_matrix> — the float tag of a sequence X of shape (L,4), 1 ≤ L ≤ 20 (1200/round, 0.03 s server delay each).
  • challenge — 6 random sequences of lengths [3,5,7,9,13,17], then it immediately expects verify <json_tags>; pass iff max|pred − true| < 1e-6.

We cannot eval the challenge sequences, and every round regenerates the secret — so we must recover the map well enough to evaluate it on arbitrary inputs.

02Unwinding the "Hamiltonian"

Expand the einsum (A[c].T[j,k] = A[c][k,j]):

energies[i] = Σj,k x_tail[j] · A[c][k,j] · X[i,k]
           = Σk X[i,k] · ( Σj A[c][k,j] · x_tail[j] )
           = X[i] · (A[c] @ x_tail)

The gauge_shift = max is just the numerically-stable softmax shift and cancels in the ratio; boltzmann/Z is softmax(energies), and observables[i] = X[i]·B[c]. Summed over channels:

T(X) = Σc softmaxi( X[i] · (A[c]·x_tail) ) · ( X[i] · B[c] )

What leaks for free — and why it's not enough

With L = 1, softmax over one element is 1 regardless of A, so T([v]) = v · (Σ_c B[c]). Four queries give Σ_c B[c] — but the length-≥3 challenges exercise the full per-channel nonlinearity, so we need every A[c], B[c] (or a functional equivalent).

03Recovery as an exact nonlinear fit

One round is system identification of a known form with 60 unknowns. Three observations make it easy:

  • Noise-free ⇒ functional equivalence suffices. The oracle returns exact float64. Match ~150 generic tags (≫ 60 params) and you match T everywhere — channel permutations and other symmetries are harmless because only T is scored.
  • B is linear given A. The softmax weights w_c depend only on A, and T = Σ_c (w_c·X)·B[c].
  • Clean analytic Jacobian. With o_c = X·B[c], val_c = w_c·o_c:
∂T/∂B[c] = wc · X
∂T/∂A[c] = outer( Xᵀ · ( wc ⊙ (oc − valc) ), x_tail )

LM over all 60 parameters with that Jacobian, vectorised across queries (padded to a common length with a −∞ energy mask). The landscape is cleanly bimodal: a restart either finds the true basin (rmse ~ 1e-15) or an obviously-wrong one (rmse > 1e-3), so success is unambiguous — restart from the U(0.5,2) prior until rmse < 1e-7.

why it generalises

A fit reaching rmse ~ 1e-15 on 150 random sequences predicts the 6 challenge sequences at ~1e-15 too — the model class is rigid and vastly over-determined.

04Surviving the network

Two problems appear only against the live service:

  • ~120 s per-connection limit. The first attempt died at round 4: 150–200 synchronous eval round-trips at ~0.18 s each is ~30 s/round. Fix: pipeline — write all eval lines, flush, then read all responses. The query phase collapses to roughly the server delay (150 × 0.03 ≈ 4.5 s) plus one RTT.
  • Unlucky fits. Some rounds need many restarts (one local round took 83 s). Fix: run the LM restarts in parallel across CPU cores, stopping at the first rmse < 1e-7. Worst-case fit drops to ~10 s.

The rest is routine: a brute-force loop for the 20-bit PoW and JSON line framing.

06Lessons

  • Vocabulary is not security. "Coupling tensors", "partition function", "gauge stabilization" — it's a 3-head softmax-attention layer. Unwind the einsum.
  • A deterministic, noise-free oracle is a gift. Exactness turns key recovery into curve fitting, and reduces the goal to "find any functional twin", sidestepping every internal symmetry.
  • Exploit linear substructure. B linear given A halves the nonlinearity and makes the Jacobian trivial to condition.
  • Interactive limits are part of the crypto. The real work was budget management — pipelining and parallel restarts to fit seven independent 60-parameter systems inside one time-limited connection.
