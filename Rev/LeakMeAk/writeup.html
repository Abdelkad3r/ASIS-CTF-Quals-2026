A flag-checker whose hash forgives too much — and the one constraint set that forgives nothing.

The shape of the problem

Each group of four flag bytes is hashed to a 32-bit word. The hash is lossy: several printable 4-byte groups map to the same target — the “trust issues” the title jokes about. What pins the flag down is everything around the hash: an error accumulator that must stay zero and two low-bit state checks that couple the groups together.

01

Recon

A stripped PIE. Three cheap gates run before the real check:

; length must be 34, prefix "ASIS{", suffix '}'
call strlen ; cmp rax, 0x22 ; jne DENIED
mov edx, 5 ; lea rsi,[ASIS{] ; call strncmp ; test eax,eax ; jne DENIED
cmp byte [rsp+0x81], 0x7d ; jne DENIED

So the flag is ASIS{ + 28 inner bytes + }. Those 28 bytes are gathered onto the stack and fed to the obfuscated core.

02

The internal hash

The 28 bytes are consumed four at a time as a big-endian word and folded into seven 32-bit dwords with the golden-ratio constant:

H[i] = (word_i * 0x9e3779b9) XOR mix_i     # word_i = big-endian bytes[4i..4i+3]

mix_i comes from a per-byte state machine — character-class counters, a cmp r10b, 0x59 (“is this byte > 'Y'?”), and two small stack arrays. For a fixed prefix it depends only on the current four bytes and is low-entropy. The identity H = word·const ^ mix holds exactly, which is what makes the hash invertible per group.

03

The acceptance conditions

The function never early-exits — it builds an error mask in ecx and checks everything together at the end:

  • ecx == 0 — the byte loop must never or in an error bit.
  • Seven cyclic equations against two rodata tables: (ror(H[i%7],13) + H[i-1]) ^ tableB[i] == tableA[i] for i = 1..7.
  • A poly-33 hash of the dwords == 0xddaacf25, and its 64-round remix == 0x376a3d36 (redundant, but checked).
  • Two low-bit state checks: s30[0] & 3 == 1 and s30[1] & 3 == 2.

All of them, or Access Denied!

04

Stage 1 — the dwords, with z3

Seven cyclic equations in seven 32-bit unknowns. With C[i] = tableA[i] ^ tableB[i] and the poly-33 target as a consistency check, z3 returns a unique solution:

for i in 1..7:  ror(H[i % 7], 13) + H[i-1] == C[i]
edx = 0; for h in H: edx = edx*33 ^ h;  edx == 0xddaacf25

H = [0x0cf6a545, 0x89397a88, 0x54c2caf9, 0xab02cb0c,
     0xcda7368c, 0xb2fab02b, 0xf6c4d21a]
05

Stage 2 — a Unicorn oracle for the mix

The mix state machine is tangled enough that hand-transcribing it invites bugs. Instead, emulate the check with Unicorn: enter just past the length/prefix gates, write the flag to the stack buffer, and hook the dword store to read (H_i, mix_i, ecx_i) each iteration and the two puts sites for the verdict.

hook 0x13c2  # mov [rsp+4*rbp+0x10], edx  -> read edx=H, esi=mix, ecx=flags
hook 0x147e  # "Access Granted"  puts
hook 0x14bb  # "Access Denied!"  puts

The emulation matches the real binary cycle for cycle (~0.16 ms per run) and confirms H = word·const ^ mix.

06

Stage 3 — invert and DFS

For each group, given the target H[i]: sample the small reachable set of mix_i, invert each to word_i = (H[i] ^ mix) · inv(const), and keep the printable ones whose emulated H matches with a clean ecx. A DFS over the one-or-two candidates per position keeps only the string the checker grants — the cross-group constraints cull the rest:

$ python3 solution/solve.py
[+] internal dwords H = ['0xcf6a545', '0x89397a88', ...]
[i=0]        '' + 'haad'
[i=1]    'haad' + 'ucrc'
 ...
[+] 1 string(s) accepted by the checker
[+] flag: ASIS{haaducrcplmekhylrozcxyxzuizs}

Flag

Confirmed on the live service — Access Granted! Correct Flag., and any single-byte change gives Access Denied! The flag reads as noise rather than leetspeak; that is the challenge (a lossy checker with exactly one printable fixed point), not a missed decode — the exhaustive search finds this and only this.

—

Takeaways

  • An accumulate-then-compare checker has no timing oracle. You cannot peel it byte by byte; you have to model the whole predicate — and z3 plus an emulator do that without hand-reversing every branch.
  • Emulate what resists static reading. The mix machine is awkward; rather than transcribe it, Unicorn is the ground truth, and one hook on the store turns it into an exact inversion oracle.
  • A lossy hash plus side constraints can still be unique. Collisions per group, but the state machine couples the groups; enumerating the small candidate tree and asking for the verdict collapses it to one.
  • Trust the search, then trust the target. A noisy-looking flag invites second-guessing, but an exhaustive search and a live confirmation settle it.
